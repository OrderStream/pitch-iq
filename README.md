# PitchIQ - Tactical Decision Training Engine

An interactive, zero-latency football decision training prototype built with HTML5 Canvas and the Web Audio API.

Designed specifically for mobile web browsers (iPhone Safari and mid-range Android), demonstrating:
- **Instant Touch Pipeline:** Direct pointerdown binding bypassing Mobile Safari's 300ms tap delay.
- **Half-Turn Body Orientation:** 45-degree angular vision cones modeling pitch scanning before receiving.
- **Optimistic Local Feedback:** Sub-millisecond visual ripples and reticles rendered on the immediate animation frame.
- **Synthesized Audio:** Built-in Web Audio API sound synthesis with zero external assets.
